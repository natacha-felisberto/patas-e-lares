📋 Requisitos do projeto
👤 Requisitos funcionais
RF01 — Página inicial

O sistema deverá possuir uma página inicial contendo:

Apresentação da plataforma;
Breve explicação sobre a proposta do projeto;
Destaques de animais disponíveis;
Botão para visualizar os animais;
Seção explicando como funciona o processo de adoção.
RF02 — Listagem de animais

O sistema deverá apresentar os animais disponíveis em formato de cards.

Cada card deverá apresentar:

Foto;
Nome;
Espécie;
Idade;
Sexo;
Porte;
Botão para visualizar os detalhes.
RF03 — Filtro de animais

O usuário deverá conseguir filtrar os animais por:

Tipo de animal;
Sexo;
Porte;
Faixa etária.
RF04 — Busca por nome

O usuário deverá poder pesquisar um animal pelo nome.

RF05 — Página de detalhes

Cada animal deverá possuir uma página ou seção própria contendo:

Foto;
Nome;
Idade;
Espécie;
Sexo;
Porte;
Personalidade;
História;
Características;
Informações adicionais;
Botão para demonstrar interesse na adoção.
RF06 — Interesse em adoção

Ao clicar em "Tenho interesse em adotar", o usuário deverá ser direcionado para um formulário de interesse.

RF07 — Formulário de interesse

O formulário deverá permitir o preenchimento de informações como:

Nome completo;
E-mail;
Telefone;
Cidade;
Tipo de residência;
Se possui outros animais;
Se já teve animais anteriormente;
Motivo pelo qual deseja adotar;
Informações adicionais.
RF08 — Validação do formulário

O sistema deverá validar os campos obrigatórios antes do envio.

Caso exista algum erro, deverá apresentar uma mensagem informando o que precisa ser corrigido.

RF09 — Confirmação

Após o preenchimento correto do formulário, o sistema deverá apresentar uma mensagem de confirmação do envio do interesse.
