# patas-e-lares


🐾 Plataforma de Adoção de Animais

Projeto desenvolvido para fins de aprendizado, prática e construção de portfólio em desenvolvimento web.

📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um site fictício voltado à adoção de animais, criado com o objetivo de praticar conceitos de desenvolvimento web e construir um projeto para portfólio profissional.

A plataforma busca representar uma solução digital que facilite a conexão entre pessoas interessadas em adotar e animais que estão procurando um novo lar.

O site permitirá que os usuários conheçam os animais disponíveis para adoção, pesquisem e filtrem os pets de acordo com suas características e consultem informações detalhadas sobre cada animal.

A primeira versão será desenvolvida utilizando HTML, CSS e JavaScript, com foco na prática dos principais conceitos de desenvolvimento web, na criação de uma interface funcional e responsiva e no desenvolvimento colaborativo entre as integrantes da equipe.

⚠️ Importante: Este é um projeto fictício desenvolvido exclusivamente para fins educacionais, de prática e composição de portfólio. Não representa uma plataforma real de adoção.

🎯 Objetivos do projeto
Objetivo principal

Desenvolver uma aplicação web fictícia relacionada à adoção de animais, utilizando o projeto como oportunidade para aprimorar conhecimentos em desenvolvimento web e construir um projeto relevante para portfólio.

Objetivos específicos
Praticar HTML5 e estrutura semântica;
Praticar CSS3 e criação de interfaces responsivas;
Desenvolver funcionalidades utilizando JavaScript;
Trabalhar com manipulação do DOM e eventos;
Desenvolver filtros e busca de informações;
Criar formulários e validações;
Praticar organização de projetos web;
Utilizar Git e GitHub para controle de versão;
Desenvolver um projeto em colaboração com outra pessoa;
Aplicar conceitos aprendidos em um projeto prático;
Criar uma aplicação que possa ser apresentada como parte do portfólio profissional.


🛠️ Tecnologias

A primeira versão do projeto utilizará:

HTML5 — estrutura das páginas;
CSS3 — estilização e responsividade;
JavaScript — interatividade e funcionalidades;

🤝 Desenvolvimento colaborativo

O projeto será desenvolvido em dupla utilizando Git e GitHub.

As tarefas serão divididas entre as integrantes e posteriormente integradas ao projeto.


🎓 Finalidade do projeto

Este projeto faz parte do processo de aprendizado e desenvolvimento de habilidades em programação, tendo como finalidade principal a construção de um projeto prático para portfólio.

A proposta é utilizar uma situação fictícia para aplicar conhecimentos de desenvolvimento web, praticar a resolução de problemas, trabalhar em equipe e demonstrar a evolução técnica das integrantes.

O projeto também poderá servir como exemplo de aplicação prática dos conhecimentos adquiridos durante os estudos.
